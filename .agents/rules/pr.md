1. Clean Architecture（整洁架构）将业务核心与框架、数据库、第三方服务隔离，依赖方向由外向内解决业务代码长期维护、测试和技术替换问题
2. SOLID（面向对象设计原则）通过单一职责、接口隔离、依赖倒置等原则，让代码低耦合、易扩展解决代码膨胀、修改风险和扩展困难问题
3. Test Driven Rules（测试驱动规则）编写代码时遵循测试要求，核心业务必须可测试，自动化验证功能正确性解决代码质量、重构风险问题
4. 12-Factor App（十二因素应用）规范应用的运行方式，例如配置分离、无状态服务、日志输出、容器部署解决云环境部署、扩容、运维问题
