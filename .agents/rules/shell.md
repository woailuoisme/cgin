# 现代化 Shell 与 CLI 工具规范 (Shell & CLI Standards)

在终端执行命令、探索文件与处理文本时，强制优先使用现代化高性能工具并遵循执行纪律：

## 1. 现代化 CLI 替代矩阵

| 原传统工具 | 强制指定现代工具 | 核心优势与适用场景 |
| :--- | :--- | :--- |
| `grep` | **`rg` (ripgrep)** | 默认尊重 `.gitignore`，多线程高速文本与正则搜索。 |
| `find` | **`fd`** | 语法简洁直观，智能大小写，快速文件/目录路径定位。 |
| `sed` | **`sd`** | 简单直观的正则替换（**仅限** Markdown 文档、注释排版与非代码文件）。 |
| `bash/zsh` | **`rtk <cmd>`** | 所有终端命令必须前缀 `rtk`，压缩输出并节省 Token。 |

## 2. 命令行执行红线禁令

1. **绝对严禁 `cd` 命令**：严禁在指令中切换当前工作目录，必须通过工具自带的路径参数（如 `Cwd`、`-C` 或 `--dir`）指定目标目录，防止上下文污染。
2. **严禁正则批量改写代码**：代码语法的迁移、重构与模式修改一律禁止使用 `sed`、`sd`、`awk`，必须统一交由 `ast-grep` 进行语法级操作。
3. **静默与非交互优先**：所有安装、构建与脚本命令必须使用非交互参数（如 `-y`、`--non-interactive`、`--batch`），杜绝因等待用户输入导致进程挂起。
4. **受控降级准则**：仅在目标环境缺失对应现代化工具时，方可临时降级为标准 POSIX 命令。
